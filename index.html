One Slack app. Separate personal agents.

Every message stays tied to the person who sent it, the machine they connected, and the projects they approved.

Each person reaches only their own agent

Alice’s message goes to Alice’s connected agent. Bob’s goes to Bob’s. A busy channel never becomes a shared machine.

No shared machine or login

Your login stays on your machine

Symma uses the coding agent you already signed into. Provider credentials do not enter Slack or the hosted gateway.

No API key to copy into a bot

You choose where the agent can work

Project folders and permissions are chosen on the connected machine. A Slack message cannot point the agent at an arbitrary path.

Only approved projects appear in Slack

Connect once. Then work from Slack.

The planned setup uses one companion install and a one-time pairing code. After that, the work starts from Slack.

  1. In Slack
    Choose “Connect my agent”

    Symma gives you a short-lived pairing code.

  2. On your machine
    Install and pair the companion

    Run the setup on the computer or cloud machine where your agent is already signed in.

  3. Then
    Choose an agent and project

    Slack shows only the machines, agents, and project folders you approved.

What stays where

Slack carries the request. Symma finds the right person. Your machine holds the agent, project files, and provider login.
