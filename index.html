01 / Ask

Start where the context already lives.

Mention Symma in a channel thread or begin in DM. The source thread becomes context for a new task—not a shared agent session.

02 / Go private

Work starts privately by default.

The bot opens a personal DM conversation while the task begins. Invoking an agent is not consent to publish what it says.

03 / Route to you

Identity decides the destination.

The gateway resolves Slack actor → owner → endpoint. Alice reaches her MacBook. Bob reaches his cloud machine. No shared agent identity in between.

04 / Run there

Your machine does the work.

A signed envelope reaches the outbound companion, which starts an already-authenticated ACP agent inside a locally allowlisted workspace.

05 / Review and share

The result is yours before it is public.

Follow up in private, keep the draft, or explicitly share it to the source thread. The publishing decision stays with the person who invoked the agent.

The difference

Not another shared agent box.

Symma keeps the convenience of one Slack app without collapsing everyone into one machine, one login, and one ambient set of permissions.
